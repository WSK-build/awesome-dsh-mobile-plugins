隐私政策

最后更新 2026-08-30。本页按代码写，不按意图写——下面每一条都能在构建本站的仓库里核对。如果哪一条和站点实际行为对不上，那是 bug，请告诉我们。

一句话版本

这是一个静态站点，没有账号，我们也不运营任何服务器。它不做任何访问统计，自身也不在你的浏览器里存任何东西。本站当前不投放广告，见广告一节。

访问统计

本站不使用任何访问统计：没有第三方统计脚本，没有计数器，没有 beacon。页面不测量、不聚合、不上报访问量，也不会向任何统计服务发起请求。因此不存在关于你这次访问的画像——我们这边没有，第三方那边也没有。

Cookie 与浏览器存储

本站自身不设置 cookie，也不加载广告，因此不涉及任何广告 cookie——若将来接入广告，广告一节会更新并说明。本站不写入 localStorage 或 sessionStorage。你的筛选、排序和搜索状态保存在 URL 里，除非你自己复制链接，否则它不会离开你的浏览器。

一个页面会加载什么

字体和样式表都由本域名提供，没有第三方网络字体。没有社交组件，没有代码管理器（tag manager），没有统计脚本，也没有广告脚本；页面自带的只有少量筛选逻辑。本站唯一的第三方脚本是插件详情页里可选的评论客户端：它的面板进入视口 400px 范围内才会被请求——页面很短时它可能在你打开后不久就加载，否则要等你滚动到评论区附近；浏览器不支持 IntersectionObserver 时则立即加载。

社区评论

插件详情页可通过 Giscus 提供评论；它是一个由 GitHub Discussions 支撑的开源组件。你选择加载评论后，浏览器会连接 giscus.app 与 GitHub。评论、反应、GitHub 用户名和时间戳会公开保存在本仓库的 GitHub Discussions 中；发表内容需要 GitHub 账号。Giscus 与 GitHub 会依照各自的条款和隐私政策处理这次交互。本站不会保存评论副本；组件只在其面板进入视口 400px 范围内时才被请求——页面很短时它可能在你打开后不久就加载，否则要等你滚动到评论区附近。

插件页面里的图片

每个插件页面会转载该项目的 README，其中可能包含图片。README 由第三方撰写，因此其中的图片本会让你的浏览器向我们无法控制的主机发起请求——追踪像素正是这样进入页面的。所以我们把这些图片限制在 GitHub 自有托管（raw.githubusercontent.com、user-images.githubusercontent.com、camo.githubusercontent.com、github.com）范围内，其余一律丢弃并保留其替代文字。由于本站本身就由 GitHub Pages 提供服务，GitHub 已经会收到你对页面本身的请求——因此保留下来的图片不会引入任何原本不在链路上的第三方。

托管

本站由 GitHub Pages 提供服务。和任何 Web 服务器一样，GitHub 需要收到你的 IP 地址才能响应请求。详见 GitHub 隐私声明。

你主动点击的链接

列表会链接到 GitHub 仓库、npm 包以及插件作者自己的站点。是否点击由你决定，点击之后你就到了别人的站点上，适用他们的条款。我们不会在这些链接上附加跟踪参数。

目录数据文件

/plugins.json 是公开发布、供任何人读取的，包括 dsh-market 插件和第三方工具。它描述的是插件本身——名称、描述、分类、安装命令——不包含任何关于本站访客的信息。

参与贡献

投稿通过 GitHub 的 pull request 提交，适用 GitHub 的条款，并具有公开仓库应有的可见性。本网站不接收任何投稿；可选的评论界面只会写入 GitHub Discussions，不会写入我们运营的表单或服务器。

广告

本站当前不投放广告：不加载任何广告脚本，也不联系任何广告网络，因此不会因广告设置 cookie。若将来接入广告，本节会更新并写明加载了什么、来自哪里。
